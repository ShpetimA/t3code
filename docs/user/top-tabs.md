# Top tabs

On wide screens, T3 Code can replace the thread sidebar with a browser-style tab strip. Open
**Settings → General → Thread navigation** and choose **Top tabs**. Compact windows and mobile
layouts continue to use the sidebar.

Threads, drafts, Settings, Usage, and the pull request list can all stay open as tabs. Individual
pull request reviews continue to open as compact right-panel tabs beside the list. The new-tab page
shows recent projects and threads, while tab badges and quick-look cards show project, branch,
environment, model, and thread status without changing tabs.

- Press `Cmd/Ctrl + T` or select **+** to open the new-tab page.
- Press `Cmd/Ctrl + W` to close the current tab.
- Hold `Cmd/Ctrl + E` to peek at thread details.
- Press `Cmd/Ctrl + 1` through `9` to jump to a visible tab.
- Drag top tabs horizontally to reorder them.
- Use a thread tab's menu to pin, settle, snooze, archive, or close it when those actions are
  available.

Active, pinned, or otherwise unsettled threads remain represented in the tab strip. Closing a tab
does not discard ongoing work; when settlement is supported, T3 Code offers the appropriate
settle-and-close action.

## Maximized thread tools

The thread's right panel remains the existing compact surface model for Diff, Files, Terminal,
Browser, Pull requests, and Agents. Maximizing that panel shows the chat as a pinned tab beside
those surfaces, so you can move between the conversation and a full-width Diff without restoring
the split view.

This maximized tab row does not add pane splitting or movable tool layouts. Restoring the panel
returns to the normal chat-and-right-panel layout.
